1) Which Python library is used in the passage to automate browser tasks?
a) BeautifulSoup
b) Requests
c) Selenium

Answer: Selenium

2) Which command installs the Selenium library?
a) install selenium
b) pip install selenium
c) python -m install selenium
d) pip get selenium
Answer: pip install selenium

3) What is the purpose of `webdriver.Chrome()` in the code?
a) To open a Firefox browser
b) To install Chrome

4) Which Selenium method opens a given URL in the browser?
a) open()
b) driver.load()
c) driver.goto()

5) In the example, what is the id of the username input field?

b) Pressing the Enter key

a) To delay closing the browser until the page loads
b) To speed up execution

Answer: To delay closing the browser until the page loads

9) Which Selenium method closes the entire browser window?
a) driver.close()
b) driver.quit()
c) browser.exit()
